# Видео работы дашборда

Сюда кладётся запись экрана длительностью до 2 минут (`dashboard_demo.mp4`).

## Сценарий видео (до 2 минут)

Запись (Windows 10): PowerPoint → Вставка → Запись экрана → «Выбрать область» —
выделить страницу отчёта → «Запись»; остановка — Win + Shift + Q, затем щёлкнуть
по видео на слайде правой кнопкой → «Сохранить мультимедиа как» → `video/dashboard_demo.mp4`.
Перед записью в Power BI свернуть панели «Фильтры», «Визуализации», «Данные»
и нажать «По размеру страницы» (правый нижний угол). Звук можно отключить кнопкой «Звук».

| Время | Действие на экране | Что демонстрируется |
|---|---|---|
| 0:00–0:10 | Дашборд без фильтров, курсор по заголовку и подписи периода | одна страница, период по умолчанию |
| 0:10–0:25 | Навести курсор на каждую карточку и подпись Δ | метрики и сравнение с прошлым периодом |
| 0:25–0:40 | «Период» → 5.0 ф1; в таблице первым стоит Нёвиллет (−23,3 п.п.) | временной фильтр, отклонение |
| 0:40–0:55 | Подсказка на столбце рейтинга, линии плана 5 и 40 % | сравнение с планом |
| 0:55–1:10 | «Роль» → Хил/Щит; график динамики и рейтинг | предметный фильтр по классу |
| 1:10–1:25 | Снять роль; «Элемент» → Пиро; диаграмма элементов | фильтр по классу, сравнение периодов |
| 1:25–1:40 | Снять элемент; «Персонаж» → Беннет | фильтр по объекту анализа |
| 1:40–1:55 | Очистить «Персонаж» и «Период» (ластик в заголовке среза), щёлкнуть столбец Фурины | перекрёстная фильтрация |
